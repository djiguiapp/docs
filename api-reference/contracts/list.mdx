---
title: "List contracts"
description: "Your company's contracts, optionally for one vehicle."
api: "GET /contract"
authMethod: "key"
---

Returns your company's contracts, most recent first, [paginated](/pagination).

## Query

<ParamField query="vehicleId" type="string">
  Only this vehicle's contracts.
</ParamField>

<ParamField query="page" default="1" type="integer">
</ParamField>

<ParamField query="limit" type="integer" default="20">
  1 to 100.
</ParamField>

## Response

<ResponseField name="data" type="object[]">
  Contracts, with the fields of [Get a contract](/api-reference/contracts/get). Their document links are valid for one hour.
</ResponseField>

<ResponseField name="page" type="integer">
</ResponseField>

<ResponseField name="limit" type="integer">
</ResponseField>

<ResponseField name="total" type="integer">
</ResponseField>
