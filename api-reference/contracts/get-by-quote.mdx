---
title: "Get a quote's contract"
sidebarTitle: "Get contract by quote"
description: "The contract a quote's payment opened, found by the quote's id."
api: "GET /contract/quote/{quoteId}"
authMethod: "key"
---

Returns the contract opened when the quote was paid, with the same fields as [Get a contract](/api-reference/contracts/get#response). Use it when you have the quote's id but not its `contractId`.

Until the quote is paid, this answers `404 contract_not_found`.

<ParamField path="quoteId" type="string" required>
  The quote's id.
</ParamField>

## Response

The contract, with the fields of [Get a contract](/api-reference/contracts/get#response).

## Errors

| Status | `code` | |
| --- | --- | --- |
| 404 | `contract_not_found` | The quote is not paid, or no quote with this id in your company. |

<RequestExample>
```bash cURL
curl https://businessapi-staging-civ.djigui.io/api/v1.0/contract/quote/6c1d8f0e-3b7a-4f5e-9a51-2d0c7e8b4a12 \
  -H "x-api-key: $DJIGUI_API_KEY"
```
</RequestExample>
