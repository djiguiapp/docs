---
title: "Get a contract"
description: "A paid quote's contract, with its ASACI certificate and documents."
api: "GET /contract/{id}"
authMethod: "key"
---

Returns a contract, opened when its quote's payment was confirmed. Its id is the quote's `contractId`. See [Contracts and certificates](/guides/contracts).

<ParamField path="id" type="string" required>
  The contract's id.
</ParamField>

## Response

<ResponseField name="id" type="string">
</ResponseField>

<ResponseField name="status" type="string">
  `pending` (waiting for the certificate or the start date), `started` (covered) or `expired`.
</ResponseField>
<ResponseField name="policyNumber" type="string | null">
  For example `2026.055.401.04217`.
</ResponseField>
<ResponseField name="startDate" type="string | null">
  First day covered, `YYYY-MM-DD`.
</ResponseField>
<ResponseField name="endDate" type="string | null">
  Last day covered, `YYYY-MM-DD`.
</ResponseField>
<ResponseField name="paymentId" type="string | null">
  The payment that opened it.
</ResponseField>
<ResponseField name="certificateStatus" type="string">
  `pending` (being requested from ASACI), `issued`, or `failed` (contact Djigui).
</ResponseField>
<ResponseField name="quote" type="object">
  The quote it was opened from.

  <Expandable title="quote">
    <ResponseField name="id" type="string">
    </ResponseField>
    <ResponseField name="amount" type="integer">Premium, francs CFA.</ResponseField>
    <ResponseField name="duration" type="integer">Months.</ResponseField>
    <ResponseField name="usage" type="string">
    </ResponseField>
    <ResponseField name="policyHolderName" type="string">
    </ResponseField>
    <ResponseField name="coverageId" type="string">
    </ResponseField>
  </Expandable>
</ResponseField>
<ResponseField name="vehicle" type="object">
  The vehicle, as in [Get a vehicle](/api-reference/vehicles/get).
</ResponseField>
<ResponseField name="certificate" type="object | null">
  The ASACI certificate, `null` until issued.

  <Expandable title="certificate">
    <ResponseField name="certificateNumber" type="string">
    </ResponseField>
    <ResponseField name="insuranceCompany" type="string">
    </ResponseField>
    <ResponseField name="effectiveDate" type="string">
    </ResponseField>
    <ResponseField name="expiryDate" type="string">
    </ResponseField>
    <ResponseField name="pdfLink" type="string">The certificate as a PDF, hosted by ASACI.</ResponseField>
    <ResponseField name="imageLink" type="string">The certificate as an image, hosted by ASACI.</ResponseField>
    <ResponseField name="qrCodeLink" type="string">Its QR code.</ResponseField>
  </Expandable>
</ResponseField>
<ResponseField name="documents" type="object">
  Download links, **valid for one hour**. Each is `null` until its file is stored.

  <Expandable title="documents">
    <ResponseField name="certificateImageUrl" type="string | null">Djigui's copy of the certificate image.</ResponseField>
    <ResponseField name="contractDocumentUrl" type="string | null">The insurance contract.</ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="created" type="string">
</ResponseField>

<ResponseField name="updated" type="string">
</ResponseField>

## Errors

| Status | `code` | |
| --- | --- | --- |
| 404 | `contract_not_found` | No contract with this id in your company. |
