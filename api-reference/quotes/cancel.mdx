---
title: "Cancel a quote"
description: "Cancel a quote nobody is paying."
api: "POST /quote/{id}/cancel"
authMethod: "key"
---

Cancels a quote that is `awaiting_payment`. The quote stays in [`GET /quote`](/api-reference/quotes/list) with the status `cancelled`, and can no longer be paid. See [Quotes](/guides/quotes#cancelling-a-quote).

Cancelling a cancelled quote again changes nothing: it answers `200` with the quote.

<ParamField path="id" type="string" required>
  The quote's id.
</ParamField>

## Response

`200 OK`, with the quote and the fields of [Create a quote](/api-reference/quotes/create#response). Its `status` is `cancelled`.

## Errors

| Status | `code` | |
| --- | --- | --- |
| 404 | `quote_not_found` | No quote with this id in your company. |
| 409 | `payment_in_progress` | A payment is waiting for the payer. Wait for it to settle. `paymentId` and `paymentUrl` are that payment's. |
| 409 | `quote_already_paid` | The quote already has a contract. |
| 410 | `quote_expired` | The quote was not paid within 24 hours. |

<RequestExample>
```bash cURL
curl -X POST https://businessapi-staging-civ.djigui.io/api/v1.0/quote/6c1d8f0e-3b7a-4f5e-9a51-2d0c7e8b4a12/cancel \
  -H "x-api-key: $DJIGUI_API_KEY"
```
</RequestExample>
