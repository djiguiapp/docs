---
title: "Get a quote"
description: "One of your quotes, with its status."
api: "GET /quote/{id}"
authMethod: "key"
---

Returns one of your quotes, with the same fields as [Create a quote](/api-reference/quotes/create#response). Once the quote expires, this answers `410 quote_expired`. See [Quotes](/guides/quotes).

<ParamField path="id" type="string" required>
  The quote's id.
</ParamField>

## Response

The quote, with the fields of [Create a quote](/api-reference/quotes/create#response).

## Errors

| Status | `code` | |
| --- | --- | --- |
| 404 | `quote_not_found` | No quote with this id in your company. |
| 410 | `quote_expired` | The quote was not paid within 24 hours. |

<RequestExample>
```bash cURL
curl https://businessapi-staging-civ.djigui.io/api/v1.0/quote/6c1d8f0e-3b7a-4f5e-9a51-2d0c7e8b4a12 \
  -H "x-api-key: $DJIGUI_API_KEY"
```
</RequestExample>
