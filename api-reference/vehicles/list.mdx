---
title: "List vehicles"
description: "Your company's vehicles, or the one with a given plate or external id."
api: "GET /vehicle"
authMethod: "key"
---

Returns your company's vehicles, most recent first, [paginated](/pagination).

Filter by `licencePlate` or `externalId` to find one vehicle: both are exact matches, so `data` holds zero or one vehicle. Given together, a vehicle must match both.

## Query

<ParamField query="licencePlate" type="string">
  Normalised as at registration: `1234 ab 01` finds `1234AB01`.
</ParamField>

<ParamField query="externalId" type="string">
  Your own reference for the vehicle.
</ParamField>

<ParamField query="page" default="1" type="integer">
</ParamField>

<ParamField query="limit" type="integer" default="20">
  1 to 100.
</ParamField>

## Response

<ResponseField name="data" type="object[]">
  Vehicles, with the fields of [Get a vehicle](/api-reference/vehicles/get).
</ResponseField>

<ResponseField name="page" type="integer">
</ResponseField>

<ResponseField name="limit" type="integer">
</ResponseField>

<ResponseField name="total" type="integer">
  Matching vehicles, across all pages.
</ResponseField>
